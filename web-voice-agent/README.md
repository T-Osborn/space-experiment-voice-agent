## 第 2 步聊天骨架

这是一个不依赖第三方 npm 包的最小 Web Voice-Agent 骨架。

当前阶段只验证：

- 浏览器麦克风语音识别入口；
- 服务端 Agent 调度接口；
- 浏览器语音播报出口；
- Web 与服务端之间的会话状态接口；
- 后续接入正式 ASR、LLM 和 TTS 的适配位置。

当前已加入基础角色配置、来源可追溯的知识检索、多实验注册和项目演示流程引擎。ASR/TTS支持百度语音、OpenAI与通用接口，尚待真实凭证和录音实测；没有接入通用 LLM。

实验路由已采用注册表设计。水稻预处理目前只是一个演示配置，新增其他实验需要通过 `config/experiments.json` 登记，不能把系统逻辑写死在水稻实验上。

实验流程引导受任务级 SOP 安全闸门控制。目前已登记20个实验目录项，仅水稻项目演示流程可用于软件联调；只有加载经过审核的流程、确认前置条件、获得宇航员反馈并满足异常分支要求后，Agent 才能继续播报下一步。Agent 不控制实验设备。

Web 界面已经接入当前流程引擎，保持语音优先，只显示当前实验、步骤和状态，不提供文字聊天输入框。

通用流程现在支持口语数字、数据读回确认、复述、状态查询、记录总结和暂停恢复。引导中询问资料不会改变当前参数；切换实验不会继承旧实验参数。实现与验证范围见 `../docs/18-语音流程确认与离线验证.md`。

语音配置可以暂缓。当前已接入20道带公开出处的核心问答，并将原题库400道未核查候选隔离；不将论文参数当作任务操作条件。核查与演练说明见 `../docs/20-专业问答与演练验收.md`。

## 当前启动方式

Windows 本机预览：双击项目根目录的 `Start-Voice-Agent.cmd`。启动器读取已有本机配置，不要求填写密钥，不自动选择音色；未配置语音也能打开界面。默认尝试 `http://127.0.0.1:8100/`，端口占用时选择后续可用端口，以终端实际打印的网址为准。保持服务窗口运行。

当前使用 `Start-Baidu-Voice-Agent.cmd` 启动T指定的音色（short_text / 4100），在本机隐藏提示中填写两项凭证，不把密钥发到聊天或写进快捷脚本。凭证存在不等于鉴权成功；本轮已实测合成并由T确认首轮录音后的语音回复，后续仍需验证实验场景。最新接入说明见 `../docs/34-百度音色4100接入.md`；旧版第17、19、31阶段文档保留历史参考，当前音色选择以4100为准。

安装 Node.js 24 后，也可在项目根目录直接运行：

```text
node web-voice-agent/server/index.js
```

然后打开：

```text
http://127.0.0.1:8080/
```

直接运行 Node 时默认端口为8080；通过 Windows 启动器启动则默认从8100开始选择。需要恢复记录时，请保持原浏览器及主机名，不要在 `localhost` 与 `127.0.0.1` 之间切换。

## 当前语音链路

```text
浏览器麦克风
  ↓ MediaRecorder
POST /api/asr/transcribe
  ↓
服务端 ASR 网关（当前等待配置上游供应商）
  ↓
POST /api/voice/turn
  ↓
服务端 AgentOrchestrator
  ↓
 知识检索与来源/执行权限判断
  ↓
返回播报文本与状态
  ↓
所选服务端 TTS（配置后）；仅显式选择浏览器模式时使用 speechSynthesis
```

当前 ASR 使用服务端网关；页面需识别和所选播报方式均配置齐全才允许录音。服务端 TTS 失败会明确报错，不自动改用浏览器音色。停止播报不会撤销已经成功保存的任务状态；可在语音恢复后请求复述。ASR/TTS 密钥均应只保留在服务端。

百度识别上传前会转换为16kHz单声道16位PCM；百度长回复会分段合成并依次播放。停止播报或开始录音会取消后续播放。自动测试只能证明模拟协议与代码逻辑，真实识别及音色体验仍需实测。

ASR 接入背景见 `../docs/14-ASR接入说明.md`，当前配置与实测边界以第31阶段说明为准。
