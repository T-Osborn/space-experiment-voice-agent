# 2.0团队独立测试指南

版本：2.0.0-beta.2；更新日期：2026-10-20。测试者可在自己的电脑独立运行，无需T的电脑保持在线。旧版升级与本次时间复测见[beta.2更新说明](49-beta2更新与复测.md)。

## 开始前需要什么

Windows、Node.js 24、带麦克风的Edge/Chrome、可访问百度语音服务的网络，以及同一语音应用完整的API Key与Secret Key。下载不需要GitHub账号，运行不需要Codex、Git或npm install。百度凭证由测试者或团队另行提供，安装包不含凭证。

## 下载及首次启动

1. 打开 https://github.com/T-Osborn/space-experiment-voice-agent/releases/tag/v2.0.0-beta.2 。在Assets下载有明确版本名的ZIP，而不是旧1.0或页面自动生成的Source code。
2. 将ZIP完整解压到新目录，例如桌面的“实验助手2.0测试版”。不要在ZIP预览中直接双击文件，不覆盖旧版唯一副本。
3. 安装Node.js 24，重开终端后 `node -v` 应为24.x。
4. 双击根目录 `Start-Baidu-Voice-Agent.cmd`。隐藏输入API Key，回车；隐藏输入Secret Key，回车。不要输入控制台中带星号的示例值。
5. 保持窗口开启，打开窗口打印的 `http://127.0.0.1:端口/`。8100被占用时启动器会另选端口，不要继续用旧标签页。
6. 页面版本应为2.0.0-beta.2，音色per=5。允许麦克风，点击“开始聆听”，说“语音帮助”，再次点击提交，等回复结束再说下一句。

启动入口只为本次PowerShell进程设置Bypass，不修改CurrentUser或LocalMachine策略。组织管理策略仍以设备要求为准；不使用PowerShell脚本的Node启动方法见下文。

## 如何测试

打开同目录 [语音测试问答表](45-2.0语音测试问答表.md)，先完成1—12知识与追问，再做13—25流程读回，26—28异常保护最后做。表里的天数、温度、编号和时间都是软件模拟输入，不据此执行实际实验。

资料问答不必先选实验。水稻演示收集参数并读回，只有你下一轮单独说“确认无误”才推进。已经说过的信息不应反复询问；缺项、模糊和矛盾内容应追问。完整九步演示作为可选测试，具体取样/包装动作以实际任务资料为准。

## 暂停不等于卡死

主动说“暂停流程”产生普通暂停，可说“恢复流程”回到原步骤。说“冷冻箱发生故障”会触发异常暂停，单说“继续”“恢复流程”或口述“地面同意”不能解除。现版本没有连接地面指令服务，无法验证真实放行。

要开始另一轮软件测试，先语音“保存记录”并检查下载，再说“重新开始”，按提示单独说“确认重新开始”。系统归档原任务后建立新演示。仅“确认无误”不能代替任务变更确认。

## 常见启动与语音问题

- 提示找不到Node：安装24.x，重开启动窗口；如果是22/25等版本，请切换为24.x。
- 报脚本执行策略错误：先确认用了此版根目录CMD入口，而不是右键直接运行PS1；无需自行修改全局执行策略。组织管理策略请交本机管理员处理。
- 页面打不开：确保启动窗口没有关闭，使用它打印的实际端口；同事电脑上的127.0.0.1表示同事自己的电脑。
- 页面能开、按钮不可用：确认运行的是Start-Baidu入口，两项密钥都已输入，不是无密钥的Start-Voice入口；刷新正确端口页面。
- 上传或播报失败：记录页面提示及识别文字；核对百度应用、开通服务、余额及网络，不能仅凭窗口显示已配置判定云接口正常。
- 提交后比较慢：每轮包含上传、识别、后端检索/核对及合成；反馈从提交到开始回应的大约秒数，不连续重复点击。
- 刷新或重启后没有旧任务：使用同一浏览器配置、同一主机名及同一端口，不要清Cookie或混用localhost与127.0.0.1。各浏览器的任务隔离。
- 运行独立的Check-Voice-Readiness显示缺密钥：它看不到另一个临时启动窗口的凭证，以实际语音页面状态及录音测试为准。

## 记录与旧版共存

每台电脑独立保存 `web-voice-agent/data/records.sqlite`，不会自动同步团队记录。重要记录可语音下载，或双击 `Backup-Experiment-Records.cmd` 备份。保留旧版目录；本次测试优先建立全新模拟记录，不自动迁移真实记录。

关闭启动窗口会停止服务，临时凭证消失，下次运行需重新输入。重新打开时尽量使用原端口和原浏览器，以便恢复本地任务。

## macOS/Linux及直接Node启动（尚待各平台语音验证）

当前未提供macOS/Linux双击安装器。安装Node.js 24后，将 `web-voice-agent/.env.example` **复制为本机** `.env`，填写两项百度凭证，保留baidu及short_text/per=5配置；已有文件时不要覆盖。该方式会在本机保存凭证，不分享此文件。在解压根目录运行 `node web-voice-agent/server/index.js`，打开 `http://127.0.0.1:8080/`，保持终端运行。Windows也可使用此Node启动方式。
