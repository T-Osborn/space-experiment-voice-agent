# 1.0团队试用指南

发布日期以GitHub Release实际发布结果为准。当前准备版本为1.0.0，基于已完成首轮真实语音接入的功能基线。

## Windows快速启动

从v1.0.0 Release下载ZIP并完整解压，安装Node.js 24后双击 `Start-Baidu-Voice-Agent.cmd`，依次在隐藏提示输入API Key、Secret Key。使用同一百度语音应用的两项完整值，不填写控制台示例中的星号。

进入窗口实际打印的网址，允许麦克风，点击开始录音，再次点击提交。语音配置必须识别和播报两端齐全。关闭服务窗口后网页无法继续请求，下次运行需重新输入凭证。下载包不需要安装Codex，也不需要第三方npm依赖。

无凭证时运行 `Start-Voice-Agent.cmd` 只能预览界面。`Check-Voice-Readiness.cmd` 仅核对保存的配置或该终端的环境变量，不能读取另一个临时输入窗口中的密钥；隐藏输入启动时以实际页面状态为准。

## macOS/Linux启动

安装Node.js 24后，在解压后的项目根目录执行：

```sh
cp web-voice-agent/.env.example web-voice-agent/.env
```

使用本机文本编辑器填写 `.env` 中的 `BAIDU_API_KEY` 和 `BAIDU_SECRET_KEY`，保留百度ASR/TTS及short_text / 4100配置。已有 `.env` 时直接编辑，勿重复复制覆盖。该文件会保存本机凭证，已被Git忽略，不要分享。

```sh
node web-voice-agent/server/index.js
```

打开 `http://127.0.0.1:8080/`，使用支持MediaRecorder的浏览器。此启动方法尚未在macOS/Linux完成真实录音人工验收，请在反馈中注明系统和浏览器。

## 第一轮：基本流程

依次说“语音帮助”“选择太空水稻实验”“开始流程”“暂停流程”，每条等播报结束后再录下一条。检查听到的回复、当前实验、当前步骤和暂停状态是否一致。这个链路已由T在Windows本机确认成功，同事仍应在自己的设备复测。

## 第二轮：读回与独立确认

以下值是软件演示输入，不是实际实验结果或通用科学阈值；仅报告虚构值，不执行物理实验动作。

1. 在首步骤的普通暂停状态说“恢复流程”。
2. 报告“培养周期九十五天，成熟度评估已完成，种子已成熟，营养液剩余百分之二十五”。
3. 检查读回是否保留95天、成熟度与百分之25，是否等待确认。读回正确后才另说“确认无误”。
4. 到温度核对步骤后报告“温度负八十点零五摄氏度”。检查是否准确读回负80.05，且没有自动推进。
5. 报告“更正温度负八十二摄氏度”。检查是否重新读回负82并重新等待确认，原读回不能直接算作新数据的确认。
6. 最后说“暂停流程”“保存记录”，确认下载成功。

若前面的报告没有被正确识别，先按提示补齐，不照着后续列表跳过。出现异常暂停时，不能用新的合格值直接解除；不要编造地面授权来完成测试。该轮真实录音尚待同事反馈，不预先标记为通过。

## 第三轮：异常与中断

在演示会话中报告“容器标签看不清”，检查异常分类追问与暂停状态。说“继续”应仍要求核对恢复依据。可说“当前状态”“本步还缺什么”“总结”查询已有记录。

按普通暂停与异常暂停分别记录反馈，避免将“停止播报”误认为实验引导暂停。播放中断后可重新录音说“再说一遍”；当前程序使用所选音色，不自动改用其他声音。

## 记录与更新

本机状态保存在 `web-voice-agent/data/records.sqlite`。保留原浏览器Cookie和主机名，重启服务后核对任务状态。不要将 `localhost` 与 `127.0.0.1` 混用。各同事的记录分别保存在各自电脑，不会自动上传GitHub。

升级前先下载重要记录或使用备份入口。将新版本解压到新目录，保留原目录；需要迁移记录时按[恢复说明](33-记录长期保存与恢复说明.md)操作，避免覆盖唯一的数据副本。
