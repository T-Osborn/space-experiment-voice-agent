## 给接入人员的步骤

1. 可以双击 `Start-Baidu-Voice-Agent.cmd` 启动临时默认音色方案，在本机隐藏提示中输入 API Key 和 Secret Key；此快捷方式指定 short_text / 0，凭证只传给这次服务进程，不保存文件，不要求声音复刻已开通。不要在聊天中发送密钥。
2. 如需保存本机或部署配置，使用 `.env.example` 或 `.env.deploy.example` 模板中的百度普通合成配置填写凭证；已有私密配置不要直接覆盖。当前模板采用 short_text、音色0。之后切换定制声音时，将服务改为 clone 并填入已开通的 voice_id，使用通用 `Start-Voice-Agent.cmd` 启动，默认音色专用快捷方式仍固定为0。
3. 双击根目录 `Check-Voice-Readiness.cmd` 检查已保存到本机 `.env` 或当前终端环境中的配置；它无法读取另一个临时启动窗口的凭证。隐藏提示启动时，以网页加载的状态为准。检查不会显示密钥或发起云请求。
4. 配置变更后重启自己的服务，再刷新页面。只有识别与播报两端均具备配置，录音按钮才启用。网页仅接受语音对话输入。
5. 实际录音验证：先说“语音帮助”，确认能收到所选音色回复；再说“选择太空水稻实验”“开始流程”，口述本次演示提供的反馈，核对读回内容后说“确认无误”。录音仅在主动点按麦克风后采集。
6. 完成演示后说“保存记录”，确认文件已下载。更多实验仍通过同一套目录、知识与流程模块逐步加入。

“配置齐全”只说明设置存在且满足适配器的本地配置检查；密钥有效性、额度、接口权限、网络和实际音色效果仍由真实调用验证。此工具不会声称这些验证已经通过。

## 接入故障时的表现

- 识别已配、所选音色未配：页面显示待补齐的音色配置，录音按钮禁用。
- 录音设备报错或麦克风在录音中断开：丢弃本轮部分录音、停止设备采集，保留原实验步骤；修复设备连接后重新录音。
- 空录音：提示重新报告，不发送给识别服务。
- 所选音色播报失败：保留已提交的任务状态，稍后用“再说一遍”复述最后回复；仍不自动切换音色。

## 验证范围

本轮测试使用模拟设备与本机接口，未实际采集用户语音。自检读取本机私密配置时，只生成配置状态，不导出或改写密钥。本轮没有增加论文、实验数据或实验操作参数；现有多实验资料与审核状态保持原有范围。

源码包可供另一台电脑启动。公网共享仍需要部署到 HTTPS 服务并配置访问令牌；本机地址不能作为其他人的访问地址。
