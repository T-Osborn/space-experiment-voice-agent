# 在轨实验语音助手 1.0

供团队下载试用、收集反馈并规划2.0。实验人员通过语音选择实验、报告数据、核对读回、确认步骤和报告异常；实际实验动作由人员完成。

## 下载与启动

在本仓库的 **Releases** 页面打开 **v1.0.0**，下载 `space-experiment-voice-agent-1.0.0.zip` 并完整解压。也可以使用仓库的 **Code → Download ZIP** 下载源码。

Windows同事按以下顺序操作：

1. 安装 [Node.js 24](https://nodejs.org/en/download)。如果已有Node，请在终端运行 `node -v`，确认版本为24.x。
2. 双击解压目录里的 `Start-Baidu-Voice-Agent.cmd`。
3. 在本机隐藏提示中依次输入同一百度语音应用的 **API Key** 和 **Secret Key**，各按一次回车。凭证只用于此次服务进程。
4. 打开窗口打印的网址，通常为 `http://127.0.0.1:8100/`。端口占用时按窗口显示的新地址打开；保持窗口运行。
5. 允许页面使用麦克风，点击“开始聆听”，说话后再点击提交，等待语音回复。

已固定使用百度音色 **4100：度小雯**。各同事需要可用的百度应用凭证；下载包不包含团队密钥。没有凭证时，可双击 `Start-Voice-Agent.cmd` 查看界面，但录音不能使用。实际语音依赖网络和百度应用服务。

macOS/Linux的Node启动方法见[团队试用指南](docs/35-1.0团队试用指南.md)。目前人工验收在Windows本机完成，其他平台需由试用者验证。

## 建议先测试

依次用语音说：“语音帮助”“选择太空水稻实验”“开始流程”“暂停流程”。每次等回复结束后再开始下一句。

然后按[试用指南](docs/35-1.0团队试用指南.md)测试数据读回、纠错、异常暂停和记录保存。使用演示数据进行软件测试，并在反馈中注明。

## 1.0包含的内容

- 语音唯一聊天输入，百度识别与音色4100播报。
- 通用多实验注册及流程引擎，20个实验目录项。
- 一套9步水稻项目演示流程；另有4套未解锁的待审流程草案。
- 36道可追溯问答、46项公开来源，检索结果保留依据。
- 报告读回后独立确认、缺失信息追问、重新核对、暂停与异常记录。
- 本机数据库自动保存、同一浏览器重启恢复、归档下载和备份。

本版已完成真实播报测试，并由T确认“语音帮助”和选择/开始/暂停三条指令成功。编号、小数、负号、噪声场景与完整九步真实语音演示仍在试用验证范围。水稻是最终展示案例，通用框架可以继续增加其他实验；目录数量不代表已有20套完整流程。

## 提交反馈

填写[反馈模板](FEEDBACK.md)交给团队负责人；有GitHub账号的同事也可以在本仓库 **Issues → New issue** 中提交“1.0试用反馈”。记录原话、期望结果、实际结果和复现步骤，方便2.0修复与比较。反馈中不要填写密钥或真实任务的私密样品资料。

## 记录与运行说明

下载到每台电脑后，服务和数据库各自在本机运行；不会自动同步团队记录。数据位于 `web-voice-agent/data`，浏览器Cookie用于找回当前任务。重要记录可以语音“保存记录”下载，或双击 `Backup-Experiment-Records.cmd` 备份。

GitHub用于提供源码和下载包。当前没有共享在线语音服务，下载后需按以上步骤运行。本版是团队试用与演示系统，尚无经过审核的飞行任务流程。

开发者在项目根目录运行 `node web-voice-agent/scripts/run-tests.js`。测试采用模拟输入和本地服务，不能作为真实识别准确率或科学审核结论。
