# 在轨实验语音助手 2.0 测试版

版本：**2.0.0-beta.1**。供同事在自己的电脑上独立测试，收集下一轮改进反馈。语音是唯一对话输入，实际实验动作由人员完成。

## 下载与启动（Windows）

1. 打开 [2.0测试版下载页](https://github.com/T-Osborn/space-experiment-voice-agent/releases/tag/v2.0.0-beta.1)，在 Assets 下载 `space-experiment-voice-agent-2.0.0-beta.1.zip`。
2. 完整解压到一个新文件夹。已有1.0时保留原文件夹和数据，不把2.0覆盖进去。
3. 安装 [Node.js 24](https://nodejs.org/en/download)。安装后如仍提示找不到Node，请关闭启动窗口再重新打开；在新终端运行 `node -v` 应显示24.x。无需安装Codex、Git或额外npm依赖。
4. 双击 **Start-Baidu-Voice-Agent.cmd**。在本机隐藏提示中依次输入同一百度语音应用的 **API Key** 和 **Secret Key**，各按回车。凭证不随安装包提供，需要测试者或团队自行准备可用凭证及语音服务额度。
5. 保持窗口开启，打开它打印的网址，通常是 `http://127.0.0.1:8100/`；端口被占用时可能是8101等，以窗口为准。建议使用Edge或Chrome并允许麦克风。
6. 点击“开始聆听”，说“语音帮助”，再次点击提交，等待语音回复后再录下一句。

本版使用百度短文本音色 **per=5（度小娇）**。两项密钥只交给此次服务进程，不保存到文件，关闭后下次需重新输入。语音识别和合成需要电脑能访问百度接口；有密钥不等于对应服务已开通或有额度。

无密钥时双击 `Start-Voice-Agent.cmd` 可查看界面。它不会自动接入语音。Windows启动入口只为本次进程设置执行策略，不修改系统或当前用户的全局策略；组织的强制策略仍以设备管理要求为准。

先测试知识问答，再测试步骤核对，最后测试故障。故障会让任务保持异常暂停；单说“继续”不能解除，这属于当前规则的预期行为。需要另一轮软件演示时，用“重新开始”→单独说“确认重新开始”，系统会归档旧记录并建立新演示任务。

## 本版支持范围

- 多实验通用框架，20个实验目录项；1套9步水稻项目演示，另有4套不能启动的待审核草案。
- 52条可引用问答、48项公开来源登记；来源数量不等于独立论文数量。知识回答必须检索，资料不足或冲突时会说明。
- 专业问答与任务操作分开；跨轮追问补充、已报参数保留、缺项追问、数据读回后独立确认。
- 普通暂停恢复、异常报告及保护、旧任务流程版本不一致的明确新建路径。
- 新版语音工作台、只读步骤进度、字段与来源显示；本机自动保存、归档下载及备份。

本版是团队测试与展示原型，未连接实验设备，尚无经过审核的飞行任务流程；设施历史指标不作为当前任务操作条件。当前不接入自由生成答案的通用大模型。真实录音效果、编号/时间读音、噪声和完整流程仍需各测试者复测。

## 数据与版本

服务和记录各自在测试者电脑上运行，不会自动同步给T或上传GitHub。数据库在 `web-voice-agent/data`。保持同一浏览器和相同网址访问；可语音“保存记录”导出，或使用 `Backup-Experiment-Records.cmd` 备份。

安装包不含实际密钥、个人实验数据库、录音、原始私人文档和开发备份。GitHub提供下载分发，当前不是一个打开网址即可跨设备使用的共享在线语音服务。

[1.0下载页](https://github.com/T-Osborn/space-experiment-voice-agent/releases/tag/v1.0.0)继续保留。开发者在项目根目录运行 `node web-voice-agent/scripts/run-tests.js`；这些软件检查不等于真实语音或实验审核。更多变化见 [发布说明](RELEASE_NOTES.md)。
